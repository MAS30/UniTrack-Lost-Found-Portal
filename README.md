# UniTrack Lost & Found Portal

## Overview
UniTrack Lost & Found Portal is a desktop-based management system developed using PyQt. The system is designed to digitize and simplify the lost-and-found process within universities and educational institutions.

The application helps administrative staff securely manage, track, verify, and return lost items through a centralized digital platform.

---

## Problem Statement
Traditional lost-and-found systems in universities are usually managed manually using handwritten tags and physical records. This creates multiple issues such as:

- Difficulty tracking lost items
- Unauthorized claiming of belongings
- Poor record management
- Dependency on specific staff members
- Inefficient searching process
- Lack of transparency and accountability

UniTrack aims to solve these issues by providing a smart digital tracking system.

---

## Objectives
- Digitize the lost-and-found workflow
- Improve item tracking efficiency
- Prevent unauthorized item collection
- Maintain centralized records
- Provide quick item search functionality
- Improve administrative transparency

## Proposed Modules

### 1. Authentication Module
Secure login system for administrative staff.

### 2. Lost Item Registration
Allows staff to register found items with details such as:
- item name
- category
- location
- date/time
- description
- image

### 3. Search & Tracking Module
Enables quick searching and filtering of stored items.

### 4. Claim Verification Module
Verifies ownership before returning items to claimants.

### 5. Analytics Dashboard
Displays:
- total found items
- returned items
- pending items
- category statistics

## Scope
The system is designed specifically for educational institutions to improve the efficiency and transparency of lost-and-found operations.
